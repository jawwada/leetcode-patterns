# Dialogflow CX applied AI field guide

The detailed PDF is in `output/pdf/dialogflow_cx_applied_ai_field_guide.pdf`.

It contains a CX introduction, detailed drive-through and Noctal chapters, Kalshi/Polymarket integrations, platform comparisons, operational guidance, and the 30 design answers already completed. Following the latest scope, no new question-bank examples were added.

Noctal's confirmed background comes from the user. The worked architectures, transcripts, IDs, numbers, and optional generative extensions are labeled proposals.

Editable content lives in `guide/`, `FOUNDATIONS.md`, and `questions/`. `BOOK.md` combines the content. `build_pdf.py` creates the PDF using ReportLab and produces a build report. It uses the Codex bundled Python runtime by default when available.
